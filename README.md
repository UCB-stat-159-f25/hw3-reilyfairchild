In this project, we took the LOSC event notebook, and added some additional features. First, I cleaned the file saving methods within the notebook to be saved to separate folders - audio, data, and figures. I also implemented a makefile, which with a single call can clean out the audio, figures, and data, as well as remove the _build folder produced by calling myst build. This project also made the ligotools an installable package, and implemented tests for the utils and readligo functions.
